# OmniPulse

A monorepo for the OmniPulse patient and clinical experience platform.

## Apps
- Web: apps/web
- Mobile: apps/mobile

## Packages
- Shared UI: packages/shared-ui
- API client: packages/api-client
- Types: packages/types
- Utilities: packages/utils

## Development
- Install dependencies: pnpm install
- Start web app: pnpm --filter @omnipulse/web dev
- Start mobile app: pnpm --filter @omnipulse/mobile start
